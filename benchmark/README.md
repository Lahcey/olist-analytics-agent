# Olist 查询测试集（280 题）

`cases.csv` 可用表格软件打开；`cases.jsonl` 供程序读取。包含 240 道可回答题和 40 道应拒答题：前者由 12 类问题覆盖 2017 年 1 月至 2018 年 8 月的 20 个月，后者是 8 类不可回答问题各 5 个例子。数量不等于 280 种独立业务场景，且部分月份与此前 11 题重叠。

参考结果由 `build_cases.py` 使用原始表独立聚合、按当前指标口径生成并冻结；它们并非人工逐题标注，也不是独立于项目数据和规则的外部标准。生成时未调用模型。结果比较严格要求列顺序和排序一致，数值按数值比较，参考值的显示精度不能任意改变。

可以执行 `.\.venv\Scripts\python.exe benchmark\verify_cases.py`，用只读视图与冻结的可回答题答案对账；这不会调用模型，也不能证明拒答题标签或口径一定正确。

在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe benchmark\run_benchmark.py --limit 20
```

默认按问题类型抽样 20 题、使用固定随机种子 42，每条 SQL 均需人工确认。`--limit 0` 为全部 280 题；会产生最多 280 次模型调用。可通过 `--seed` 更换随机抽样。确认免费额度和费用之后再运行。

执行过程中每题即时保存到 `benchmark/results/`，不写入 API Key 或数据库密码；跳过题不进入分母，接口及查询错误计入已测试题。不可回答题即使生成了 SQL 也不会执行。汇总分列可回答结果正确率与拒答率；题量、样本、模型和运行次数限制见主 README。

如有意识地选择 `--auto-execute`，通过 SQL 检查的可回答题不会逐一人工确认。它仅用于本机隔离的公开练习数据库；受限账号、只读事务、超时、SQL 检查并非生产安全保证。默认使用人工模式。
